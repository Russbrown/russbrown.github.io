I had been an economics graduate for about 5 years when I really started thinking seriously about what it was that I wanted to wake up and work on for the next 40 years. I'm not sure what initially made me think I was bright enough to be able to build a website but at some point the idea came to me and I spent a lot of time musing about which course to go on, projecting when I would be able to leave the shitty job I was in.


I plodded on for six months with this idea in my head, researching more and more, dipping a toe in code here and there. I built some really stinky websites; Brownspace, Pointlessview are two I can remember. I spent a LOT of time designing and redesigning my 'portfolio' site. I should publish a post that charts these early failures, like mis-shapen flying machines that spluttered, flapped and ultimately crashed to the ground.


I attended a night course supposedly on web development, which did serve one purpose. It showed me that I had got further with my own part time study than I ever got with a light weight course on basic web development, using outdated techniques and software.


After learning precious little on the course, shit got serious. I stopped going out as much and spent more and more time learning to code, I got a gig to build a friends website for her and this ramped it up another gear as I now had a project for a real person with a real deadline.

This [book](http://www.amazon.co.uk/CSS-Missing-David-Sawyer-McFarland/dp/1491918055/ref=pd_sim_14_23?ie=UTF8&dpID=41n%2BtLM%2BxnL&dpSrc=sims&preST=_AC_UL160_SR122%2C160_&refRID=1RN0M4MNK8C0HPS7KG9Y) was the single most important book I think I've ever bought. It took me from a flailing code buffoon to bad code monkey and that was a giant leap.

After finishing this project off, I started looking for the next thing and that seemed to be building a website with a CMS. I googled and asked friends and Wordpress seemed to be the big one so I started out trying to figure it out. This is probably the hardest thing I've ever learned, bear in mind I had no prior programming experience, I didnt know what PHP was or a web server or ANYTHING. I was a stranger in a vast unknown world. 

Eventually, through a hell of a lot of googling and making a lot of mistakes I was able to figure it out, I had built my own theme for a site I'd called Northern Div. This was my (terribly clever, I thought) name for my online web design presence. The site showed design work I'd done (something that I had also been working a lot on and was improving steadily) as well as a few sites I wasnt deeply ashamed of. I had just about enough work to not look like a completely unemployable idiot, or so i thought anyway.

Its worth noting that to get here I had started getting up at 4:30am and working for a few hours before going to work, I would make a big brew of coffee and settle down to work. It was bloody hard but it got me where I wanted to be faster and this was probably the turning point between, websites as a hobby and websites as a profession.

By this time my job situation had improved, I was in a reasonably good job in IT systems admin and I got to put my web skills into practice a little but I was sure now that I wanted to create websites for a living and started looking around for someone daft enough to let me loose...
